--cpu-profile строка               Записать профиль CPU в файл

--diff-since строка                Показать изменения с указанной исторической точки (SHA коммита, ветка, тег или дата)

--export-graph строка              Экспортировать граф: .html для интерактива, .png/.svg для статики (авто-имена, если пусто)

--feedback-reset                   Сбросить все данные обратной связи к значениям по умолчанию
--feedback-show                    Показать текущий статус обратной связи и корректировки весов
--file-beads-limit int             Максимум закрытых beads для показа (используйте с --robot-file-beads) (по умолч. 20)

--forecast-sprint строка           Фильтровать прогноз по ID спринта

--history-limit int                Максимум анализируемых коммитов (0 = безлимит) (по умолч. 500)
